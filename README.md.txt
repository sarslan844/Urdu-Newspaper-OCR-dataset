# Urdu OCR Data Preparation Pipeline (Project Showcase)

> A portfolio showcase of an OCR data preparation pipeline developed for Urdu newspaper documents.

---

## 📌 About This Project

This repository showcases my experience working on an OCR (Optical Character Recognition) data preparation project during my professional work.

The project focused on preparing high-quality datasets for training and evaluating Urdu OCR models by processing scanned newspaper documents.

> **Note:** The original source code, datasets, trained models, and internal documentation are **not included** because they contain confidential company information. This repository is intended to demonstrate the project's workflow, technologies, and my technical contributions.

---

# Project Objectives

- Prepare high-quality OCR datasets
- Process scanned Urdu newspaper documents
- Extract Urdu text from images
- Generate structured image-text pairs
- Improve dataset quality through preprocessing and verification
- Automate repetitive data preparation tasks

---

# My Responsibilities

During this project, I worked on:
